## 動画の再生について（2026-09-17 実測）

- ヘッドレスEdgeで計測。**画面に入った時点で3本とも再生される**（wide t=5.08 / table t=5.82 / grill t=5.82・`paused=false`）
- `--autoplay-policy=document-user-activation-required` で自動再生を禁止しても、**ミュート動画なので再生された**
- 画面外では `readyState=0`＝読み込まない（通信量対策）。スクロールして入った瞬間に読み込んで再生する
- ⚠️ **iOSの低電力モードだけは実機でしか再現できない。**そのため `play()` が拒否されたら
  **黄色い再生ボタンが出る**フォールバックを入れてある（play()を強制的に失敗させて表示を確認済み）
